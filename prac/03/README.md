# Семинар 3

Тема: SCD в Clickhouse.

## С чего начать

### Запуск

**Запуск контейнеров:**

```sh
make run
```

Все томы монтируются в корне локально для ручной отладки и изучения устройства БД.

### Настройка и прогрев

**Полная настройка:**

Создаст схему БД, сгенерирует и загрузит все датасеты в таблицы.

```sh
make setup
```

**Выборочная настройка:**

**Создание схемы:**

```sh
make schema
```

**Генерация датасетов:**

Сгенерирует датасеты в `data/`

```sh
make gen-datasets
```

Загрузит сгенерированные датасеты из `data/` в таблицы.

**Загрузка датасетов:**

```sh
make load-datasets
```

### Очистка

Удалит все данные в ClickHouse и восстановит БД в изначальное состояние.

```sh
make teardown
```
