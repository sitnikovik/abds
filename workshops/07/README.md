# Оркестрация данных

Воркшоп направлен на освоение базовых навыков работы с [Apache Airflow](https://airflow.apache.org/)
через выполнения заданий, связанных с БД ClickHouse с прошлых занятий.

⚠️ Перед выполнением заданий выполните команду в терминале

```sh
# Создаст виртуальное окружение Python и установит зависимости
make venv
```

## Задания

### 1. Экспорт свежих показаний

Выгрузите в .csv все новые показания по квартирам за последние 24 часа.

- Адрес
- T1
- T2
- Дата (dd.mm.YYYY)

### 2. Расчет суточного потребления

Посчитайте суточное потребление по всем квартирами в рублях и выгрузите в .csv

> Можно задать любой тариф в запросе выборки

- Адрес
- T1
- T2
- Сумма в рублях
- Дата (dd.mm.YYYY)

### 3. Проверка качества данных

Проверяем:

- `gauges.t2` >= `gauges.t1`
- `gauges.flat_id` есть в таблице `flats`
- нет дублей по `id`, `flat_id`, `sent_at` в таблице `gauges`
- `flats.area` > 0

🚨 И **алертим** через отдельную задачу с `print()` соответствующее сообщение если что-то не прошло проверку, например,
`"flat 1243 has t2 > t1 (5123 > 233)"` [(см. XCOM)](https://airflow.apache.org/docs/apache-airflow/stable/core-concepts/xcoms.html#object-storage-xcom-backend:~:text=dictionary%20of%20values.-,An,-example%20of%20pushing)
